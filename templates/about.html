About

FracHIV-SITA Lab

A final-year Applied Mathematics thesis dashboard for fractional-order HIV transmission modelling.

Thesis Project

This dashboard was built as part of a final-year Applied Mathematics thesis on fractional-order HIV transmission modelling with social behaviour interventions.

The model extends classical compartmental epidemiology by incorporating Caputo fractional derivatives, enabling memory-driven dynamics not captured by ordinary ODEs.

Technology Stack
  • Python / Flask — backend API and simulation engine
  • NumPy / SciPy — numerical computation and Gamma function
  • Pandas — data export
  • Plotly.js — interactive scientific charts
  • Bootstrap 5 — responsive layout
Disclaimer

This dashboard is for academic and educational purposes only. It is not intended for clinical prediction, medical advice, or public health policy decisions. All simulation results are based on a simplified mathematical model.
