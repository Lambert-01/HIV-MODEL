SITA Flow Diagram
SITA Compartments

S(t) — Susceptible individuals at risk of infection.

I(t) — Infected, untreated individuals who can transmit.

T(t) — Treated individuals with reduced transmission (η).

A(t) — AIDS-stage individuals with high mortality (d).

Caputo Fractional Derivative

The Caputo derivative of order q ∈ (0,1] generalises the ordinary derivative. When q = 1, the model reduces to the standard ODE system.

For q < 1, the system retains memory of past states via the Gamma function weighting, producing the Mittag-Leffler relaxation behaviour.

Social Interventions

u₁ — Awareness & education reduces effective β₀.

u₂ — Safer behaviour / condom use reduces β₀.

u₃ — Testing boosts treatment rate τ.

u₄ — Adherence reduces progression rate ρ.

Basic Reproduction Number R₀

R₀ measures average secondary infections from one case in a fully susceptible population.

  • R₀ < 1 — Epidemic controlled
  • R₀ = 1 — Threshold / endemic
  • R₀ > 1 — Epidemic persistent
Gamma & Mittag-Leffler

The Gamma function Γ(q+1) normalises the fractional step weights in the Caputo solver.

The Mittag-Leffler function E_q(−λt^q) describes the fractional relaxation, generalising the exponential e^(−λt) of ordinary models.

Sensitivity Analysis

Normalised sensitivity index of R₀ with respect to parameter p:

\(\Upsilon_p^{\mathcal{R}_0} = \dfrac{\partial \mathcal{R}_0}{\partial p}\cdot\dfrac{p}{\mathcal{R}_0}\)

Positive index → parameter increases R₀. Negative → reduces R₀. Used to rank intervention effectiveness.

FracHIV-SITA Lab is an interactive computational environment for simulating the fractional-order SITA HIV transmission model with social behaviour interventions.

It supports the methodology and results chapters by presenting parameter configuration, intervention impact, R0 threshold behaviour, phase dynamics, fractional memory effects, sensitivity ranking, scenario comparison, and exportable thesis outputs.
