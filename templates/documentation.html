Model Documentation

FracHIV-SITA Model

Mathematical foundations of the fractional-order HIV SITA model with social behaviour interventions.

SITA Compartments

The model tracks four populations: S (susceptible), I (infected), T (treated), A (AIDS). The force of infection λ = β_eff(I + ηT)/N drives transitions from S to I.

Fractional Order q

The Caputo derivative of order q ∈ (0,1] introduces memory. The solver uses a fractional Euler scheme with Gamma-weighted history. q = 1 recovers the ordinary ODE model.

Reproduction Number R₀

R₀ = (β_eff / (τ_eff + δ + μ)) × (1 + ητ_eff / (ρ_eff + μ)). Values below 1 indicate disease-free stability. Values above 1 indicate endemic persistence.

Interventions

β_eff = β₀(1−u₁)(1−u₂) reduces transmission. τ_eff = τ(1+u₃) boosts treatment uptake. ρ_eff = ρ(1−u₄) reduces AIDS progression. All u_i ∈ [0,1].

Sensitivity Analysis

Normalised sensitivity indices rank which parameters most strongly increase or decrease R₀. Positive index → worsens epidemic. Negative index → controls epidemic.

Export & Reproducibility

CSV export provides full time-series data. JSON export saves all parameters. Plotly charts support PNG export. All results are reproducible from the parameter set.
