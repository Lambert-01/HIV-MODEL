# FracHIV-SITA Lab

A Flask-based fractional-order HIV SITA simulation dashboard for an Applied Mathematics final-year thesis.

## Run

```powershell
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000/dashboard`.

## Main Features

- Fractional-order SITA simulation with Caputo-style memory.
- Social behaviour interventions for awareness, safer behaviour, testing, and adherence.
- R0, epidemic status, peak infection, final states, scenario comparison, sensitivity analysis, memory comparison, R0 surface, and CSV export.
